# Support

## Getting help

For usage help and troubleshooting:

- Read `README.md` first for commands, flags, and output files.
- Search existing GitHub issues for similar problems.
- Open a new issue with a minimal reproduction when needed.

## What to include in support requests

- Operating system and Node.js version.
- Exact command used (including flags).
- Relevant logs and error output.
- `project-report/summary.md` and `project-report/decision.json` if applicable.
- Steps to reproduce.

## Security issues

For vulnerabilities, do not open public issues.
Please follow `SECURITY.md`.

## Feature requests

Open an issue with:

- Problem statement.
- Why current behavior is insufficient.
- Proposed behavior and expected output.
- Any trade-offs or compatibility concerns.
